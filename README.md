# teewer.mn

Үйлдвэрлэлийн овортой ачааны (нүүрс, хүдэр, баяжмал, шохойн чулуу, хайрга, дайрга, элс) тээврийн урвуу тендерийн платформ. Компани зар тавьж, жолооч нар битүүмжилсэн үнийн санал өгнө, хамгийн бага санал ялна. Туршилтын бүс нь Дархан-Уул.

## Ажиллуулах

```bash
npm install
cp .env.example .env        # утгуудыг бөглөнө
npm run vapid               # гарсан 2 түлхүүрийг .env-д хуулна
npm run db:push             # өгөгдлийн сан үүсгэнэ
npm run db:seed             # ADMIN_PHONE / ADMIN_PASSWORD-оор админ үүсгэнэ
npm run dev                 # http://localhost:3000
```

## Хуурамч өгөгдлөөр турших

```bash
npm run demo
```

5 долоо хоногийн өмнөөс өнөөдрийг хүртэлх хугацаанд 3 компанийн 3 байнгын чиглэлийг 14 жолоочтой бүтэн эргүүлнэ. Нийт 18 тендер үүснэ. Сайтын ашигладаг service функцийг яг ижлээр дуудна: санал өгөх, сонгох, татгалзах, хугацаа хэтрэх, ирээгүй, рейс, төлбөр. Жолооч нар зөвхөн өөрийн үр дүнг мэдэж, дараагийн удаа үнээ тохируулна. Тайланд тендер бүрийн үйл явдал, жолоочийн үзүүлэлт, үнийн хандлага гарна.

Энэ долоо хоногийн гурван тендер өөр өөр шатанд үлдэнэ: санал авч буй, сонголт хүлээж буй, гүйцэтгэж буй. Нууц үг бүгдэд нь `demo1234`:

| Утас | Хэн | Юу харах |
|---|---|---|
| 88000001 | Дархан Төмөрлөг ХХК | баяжмалын тендер санал авч байна |
| 88000002 | Дархан Түлш ХХК | нүүрсний тендер: хамгийн бага саналуудаас сонгох ээлж |
| 88000003 | Сэлэнгэ Бетон ХХК | дайргын ажил явагдаж байна, нэг жолооч ирээгүй |
| 99000001 | Б. Болд (жолооч) | баяжмалын тендерт санал өгөөгүй, өөрөө туршина уу |

**Анхааруулга:** `npm run demo` админаас бусад бүх өгөгдлийг устгадаг. Бодит (Supabase) сан дээр өөрөө зогсоно. Хуурамч өгөгдлөөр турших бол тусдаа туршилтын Supabase төсөл үүсгээд `DEMO_FORCE=1 npm run demo` ажиллуулна.

## Утасны дугаар баталгаажуулах (Verify.MN)

Компани болон жолооч бүртгүүлэхдээ утасны дугаараа баталгаажуулна:

1. Хэрэглэгч дугаараа оруулаад «Баталгаажуулах» дарна. Сервер Verify.MN дээр 6 оронтой кодтой сесс үүсгэнэ.
2. Хэрэглэгч тэр кодыг **өөрийн утаснаас** 144773 руу SMS-ээр илгээнэ. SMS-ийн үнэ 150₮ бөгөөд хэрэглэгч төлнө. Утсан дээр «SMS бичих» товч SMS аппыг код нь бөглөгдсөн байдлаар нээнэ.
3. Сайт 3 секунд тутам `GET /sessions/:id`-ээр төлөвийг шалгаж, `VERIFIED` болмогц бүртгүүлэхийг зөвшөөрнө.

Аюулгүй байдал:
- Нэг баталгаажуулалтыг зөвхөн тэр дугаарт, нэг удаа, баталгаажснаас хойш 60 минутын дотор ашиглана.
- Нэг дугаараас цагт 5-аас олон оролдлого хийх боломжгүй.
- `sessionId` клиент рүү илгээгддэггүй.

Тохиргоо (`.env`):
- `VERIFY_MN_API_KEY`: Developer Console-оос авсан түлхүүр. Тохируулсан бол бодит SMS ажиллана.
- `VERIFY_MN_MOCK="1"`: зөвхөн локал туршилтад, SMS-гүйгээр 4 секундэд баталгаажна. **Интернэтэд гаргахаас өмнө заавал устгана.**
- `APP_URL="https://teewer.mn"`: байршуулсны дараа тохируулна. Тэгвэл Verify.MN `/api/verify/callback` руу мэдэгдэл илгээнэ. Сайт үр дүнг заавал Verify.MN-ээс дахин шалгадаг.

## Урсгал

1. Компани болон жолооч утсаа Verify.MN-ээр баталгаажуулж бүртгүүлнэ. **Жолооч** шууд идэвхжинэ. **Компанийг** админ шалгаж баталгаажуулна (`/admin`), учир нь зар нь бүх жолоочид мэдэгдэл болж очдог. Админ хэнийг ч хааж болно.
2. Компани зар оруулна. Идэвхтэй бүх жолоочид push мэдэгдэл очно.
3. Жолооч үнээ санал болгоно. Бусдын үнийг харахгүй, компани ч хаагдах хүртэл зөвхөн саналын тоог харна.
4. Тендер хаагдахад саналууд үнээр эрэмбэлэгдэнэ. Хамгийн бага N санал автоматаар сонгогдоно.
5. Сонгогдсон жолооч `CONFIRM_HOURS` цагийн дотор баталгаажуулна. Татгалзвал эсвэл хугацаа дуусвал дараагийн хамгийн бага санал автоматаар сонгогдоно.
6. Жолооч рейс бүрийн жингийн тасалбарыг (тонн, дугаар, зураг) бүртгэнэ, компани батална, олох дүн автоматаар бодогдоно.
7. Компани төлбөрийг шууд шилжүүлээд бүртгэнэ, жолооч хүлээн авснаа баталгаажуулна. Платформ мөнгө дамжуулахгүй.
8. Баталгаажуулаад ирээгүй бол компани «Ирээгүй» гэж тэмдэглэнэ. Суудал дараагийнхад шилжиж, жолоочийн оноо хасагдана. `NO_SHOW_LIMIT` удаа давтвал `SUSPEND_DAYS` хоног хаагдана.

## Байнгын чиглэл (загвар)

Компани нэг чиглэлд байнга тээвэр хийдэг бол загвар болгон хадгална. Хадгалах хоёр арга бий: зар оруулахдаа тэмдэглэх, эсвэл нийтэлсэн зарын хуудаснаас «Байнгын чиглэл болгох»-ыг дарах.

- «Шууд нийтлэх» товч нэг товшилтоор шинэ тендер зарлана. Огноог загварт хадгалсан хугацаагаар автоматаар тооцно.
- Жолооч нар тендер бүрт шинээр, битүүмжилсэн үнээр өрсөлдөнө. Өмнө нь ялсан жолоочид давуу эрх байхгүй.
- «Байнгын чиглэл» хуудсанд тендер бүрийн саналын тоо, доод үнэ, сонгогдсон дундаж үнэ, хүргэсэн тонн харагдана.
- Дахин нийтлэхдээ чиглэл, ачаа, машин эсвэл үнийн нэгжийг өөрчилбөл тэр зар загварын түүхэнд орохгүй. Ингэснээр үнийн хандлага бохирдохгүй.

## Тохиргоо

Дүрэм болон хураамж [lib/constants.ts](lib/constants.ts)-д байна:

- доод хэмжээ: 100 тн
- баталгаажуулах хугацаа: 3 цаг
- ирээгүй тооны хязгаар
- зарын хураамж болон амжилтын хураамж: одоогоор 0

## Production

- Өгөгдлийн сан нь **Supabase PostgreSQL** (Токио, ap-northeast-1). Холболтын мөрийг Supabase → **Connect → ORMs → Prisma**-аас авна.
  - Тасралтгүй ажилладаг сервер (локал, VPS): `DATABASE_URL`-д **5432 session pooler** + `?connection_limit=5`. Query бүр нэг удаа очиж ирнэ (Монголоос ~90 мс).
  - Vercel зэрэг serverless: `DATABASE_URL`-д 6543 transaction pooler + `?pgbouncer=true`. Query бүр ойролцоогоор 5 дахин удаан тул вэб серверийг сантайгаа нэг бүсэд байрлуулна.
  - Нэг л хувьсагч (`DATABASE_URL`) байна. Бүтэц өөрчлөх `npm run db:push`-ийг локал дээрээс (5432) ажиллуулна.
- `npm run db:push` бүтэц үүсгэсний дараа [prisma/rls.sql](prisma/rls.sql)-ийг ажиллуулна. Энэ нь бүх хүснэгт дээр RLS асааж, Supabase Data API (publishable key)-аар өгөгдөл унших замыг хаана. Шинэ хүснэгт нэмсний дараа заавал `npm run db:push`-ээр ажиллуулаарай.
- Хугацаа дууссан баталгаажуулалтыг цагт нь шилжүүлэхийн тулд `/api/cron?key=CRON_SECRET`-ийг 5 минут тутам дуудна. Хуудас ачаалах бүрт ч мөн шалгагддаг.
- Web push нь Android Chrome дээр шууд ажиллана. iPhone дээр сайтыг «Home Screen»-д нэмсэн үед л ажиллана (iOS 16.4+).
- Жингийн тасалбарын зураг өгөгдлийн санд хадгалагдана (утсан дээр шахагдсан, ~200–400 KB).

## Бүтэц

- `lib/services/`: бизнесийн логик (company, driver). Сайт болон `npm run demo` хоёулаа эндээс дуудна.
- `app/actions/`: серверийн үйлдлүүд. Нэвтрэлт шалгаж, service дуудаж, мессежийг орчуулж, мэдэгдэл илгээнэ.
- `lib/workflow.ts`: тендерийн дүрэм (хаах, дараагийнхад шилжүүлэх, ирээгүй, олох дүн)
- `lib/clock.ts`: одоогийн цаг. Симуляци цагийг урагшлуулахад ашиглана.
- `lib/i18n/`: mn / en / zh толь бичиг
- `app/company`, `app/driver`, `app/admin`: хуудсууд
